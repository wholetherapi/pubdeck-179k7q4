# Catalogue conventions

Every paper receives exactly one checklist entry in `catalog/publications.md`.

Entry shape:

- [x] **PUB-YYYY-NNN** — *Paper title* (Venue) — paper: <preprint URL> — code: <code repository URL>

Rules:

- Identifiers are assigned sequentially within the calendar year.
- `paper:` always points at the arXiv/preprint record.
- `code:` is present only when the paper's code repository has actually been
  publicly released. A repository that merely exists is not enough.
- Entries are appended at the end of the checklist in identifier order.
- Release branches carry the same checklist plus a release note file.
